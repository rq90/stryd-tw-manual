# Stryd 台灣安裝與使用手冊

[開啟繁體中文手冊](https://rq90.github.io/stryd-tw-manual/) · [查看跑錶相容性](https://rq90.github.io/stryd-tw-manual/#watch) · [故障排除](https://rq90.github.io/stryd-tw-manual/#help)

第一次使用 Stryd，可以從確認跑錶開始，依序完成充電、手機設定、扣鞋、跑錶配對與第一次跑步。手冊將「跑動時看瓦數」、「執行 Stryd 日曆課表」及「把含功率的活動送到 RQ」分開核對，並附上各品牌的文件依據。

本專案是台灣手冊的獨立預覽。[台灣官網與聯絡方式](https://www.stryd.tw/)及[既有 GitBook](https://strydtaiwan.gitbook.io/stryd/)仍可使用。

## 本階段的資料

- [178 頁舊手冊逐頁去向](research/migration.md)，含舊網址、新版入口、取捨與待查條件。
- [原廠安裝手冊比較與架構選擇](research/structure.md)，比較 Polar H10、COROS POD 2、Garmin Running Dynamics Pod 與 Stryd。
- [網頁檢查與實機待驗項目](research/verification.md)，記錄哪些檢查已有結果，以及下一位實測者需要觀察什麼。
- [貢獻與預覽方式](CONTRIBUTING.md)，包含修改、建置、來源與圖片規則。

## 本機開啟

下載專案後，直接開啟 `docs/index.html`。網頁、自製扣鞋示意圖及手機版樣式都隨專案提供。引用的原廠說明需連線閱讀。
