先在熟悉的路線輕鬆跑一小段。這趟只要確認兩件事：跑動時看得到 Stryd 瓦數，儲存後找得到同一段功率曲線。

  1. 起跑前看連線。穿好跑鞋、移動幾步，打開剛設定的跑步模式，在感測器畫面確認 Stryd 已連線。若手錶也能從手腕估算功率，請依該錶款配對說明核對資料來源。使用 Garmin Stryd Zones 的跑者，切到這個欄位。
  2. 啟動活動。按下開始，確認時間持續增加。慢跑一小段，在安全處查看功率（W）是否隨跑動更新。Duo 必須由相容手錶或 Stryd App 開始記錄，才會將這次跑步寫入感測器記憶體。
  3. 停止並儲存。在原本開始記錄的手錶或 App 結束活動，選擇「儲存」。用手錶記錄時，先同步至該品牌的 App。打開剛剛那一筆跑步，以開始時間、跑步時長及功率曲線核對結果。
沒有相容手錶，如何用手機記錄？

把已配對的 Stryd 扣上鞋，打開手機 Stryd App。首頁左上角的感測器圖示旁出現綠點，就代表已連線。從 Calendar（行事曆）的「＋」選 Start Run，選 Outdoor（戶外）或 Indoor（室內），按播放鍵開始。結束時按停止，再按 Finish Run 保留活動。回行事曆點開這一筆即可看功率。

我要在 Stryd 裡看完整資料

若使用 COROS、Polar 或 Suunto，先讓手錶品牌的活動匯入 Stryd，再用手機補上感測器內的進階數據。靠近感測器，打開 Stryd App，依序進入 Settings → Paired Devices → Stryd → Sync Stryd。保持 App 在前景，同步結束後在 Review Offline Runs 選同一時段的活動合併，再按 Continue。

使用 5.0 或 Next Gen 的單顆或 Duo，且有有效 Stryd 會籍，可另外同步 Footpath 足跡圖。跑後把感測器放在手機旁，打開 Stryd App。在 Settings → Footpath Sync Settings 開啟 Footpath Auto Sync，或點首頁的感測器圖示選 Footpath Sync 手動同步。完成後在網頁版 PowerCenter 的 Footpath Visualization 查看。

完成確認　你能在剛儲存的那筆活動裡，找到與試跑時段對應的瓦數變化。要傳到 RQ，再到 RQ 開啟同一筆，確認其中也有功率資料。
