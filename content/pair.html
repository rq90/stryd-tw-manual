穿上已扣好 Stryd 的跑鞋，移動腳讓感測器喚醒，再打開自己平常使用的跑步模式。選下方品牌查看配對位置與成功畫面。

Garmin｜將 Stryd Zones 加到跑步畫面
  1. 在手機的 Stryd App 打開設定 → Connected Accounts，連接 Garmin Connect；若也要同步課表，開啟匯入活動及匯出課表權限。在已配對 Stryd 的裝置頁記下 ANT+ ID。
  2. 在手機開啟 Connect IQ，為這支錶安裝 Stryd Zones 資料欄位。在欄位設定填入自己的 Stryd 使用者名稱與 ANT+ ID，儲存並同步手錶。
  3. 手錶進入「感測器與配件」→「新增」→「步頻感測器／Foot Pod」。移動腳，選 FP-數字，核對數字與 ANT+ ID 相同。5.0 或 Duo 若搭配支援跑步動態的錶，可另配同組 ID 的 RD Pod。PWR 或藍牙 FP-STRYD 不是這一步要啟用的連線。
  4. 手錶進入「跑步」→「跑步設定」→「資料畫面」，新增一欄 Connect IQ → Stryd Zones。若這個跑步模式有 Garmin 內建「跑步功率」，關閉它以免混入另一組瓦數。在「系統」→「資料記錄」可選每秒記錄。

試跑時看這裡：切到剛加入的 Stryd Zones 畫面，小跑時瓦數會跟著變。越野或跑步機模式要分別加入欄位。若要執行課表，支援行事曆的錶在「訓練」→「訓練行事曆」選當天課表；Forerunner 55 等指定舊款則開啟獨立的 Stryd Workout App。

COROS｜配對 STRYD 並加入跑步功率
  1. 手錶進入「系統」→「配件」→「新增」。PACE 2、APEX／APEX Pro、VERTIX 選 ANT+；PACE 3／4／Pro、APEX 2／2 Pro／4、VERTIX 2／2S、NOMAD 選藍牙。ANT+ 搜尋時選 STRYD；藍牙則辨識 Stryd5 或 StrydX。Duo 只要選其中一個感測器。
  2. 在 COROS App 的裝置頁選手錶 → 活動設定 → 跑步 → 活動資料頁，加入 Running Power（跑步功率）並儲存。回到錶上的跑步起始畫面，等 S 圖示常亮才開始，小跑時查看瓦數。
  3. 要將紀錄送到 Stryd，在 Stryd App 設定 → Connected Accounts 連接 COROS，並允許跑步功率資料。要看 Duo 左右平衡，先等活動進入 Stryd，再到裝置頁執行 Offline Sync。

要跟 Stryd 課表跑：在 Stryd 的 COROS 帳號設定開啟 Import Activities、Export Workouts。首次在 COROS App 裝置頁打開 Training Plan Library，加入 Stryd Training Plan。等兩邊行事曆出現近期課表、手機同步手錶後，到錶上 Training Plan 選今天。原廠只推送未來七天，彈性分段可能需要按圈鍵換段。

Apple Watch｜在手錶的 Stryd App 開跑
  1. 先在 iPhone 的 Stryd App 配對感測器，再開 iPhone 的「Watch」App，找到 Stryd 並安裝到手錶。舊錶先看 App Store 的「相容性」；本次核對台灣版需要 watchOS 9.2 以上。
  2. 解鎖手錶並開啟 Stryd。若錶面提示配對，到 iPhone 的 Stryd 設定點 Pair Apple Watch。
  3. 在手錶的 Stryd App 選 Open Run 或戶外跑步，等感測器連線後開始。試跑時看功率，結束後在 Stryd 行事曆查看同一筆活動。若 Stryd 行事曆已排課，可從 Upcoming Runs 選課表。

Pixel Watch／Galaxy Watch｜使用 Stryd Wear

確認手錶是 Wear OS 3 以上。在 Android 手機的 Stryd App 配對感測器，從 Google Play 安裝 Stryd Wear 至手錶。用同一個 Stryd 帳號登入手錶，允許鄰近裝置與定位。

手錶選 Run → Free Run，等裝置已連線再開始；小跑時查看瓦數。Stryd 行事曆有當日課表時，改選 Today’s Workout。較早採 Tizen 的 Galaxy Watch 請查舊款適用方案。原廠 Wear OS 指南與舊款說明

Suunto｜配對 Foot Pod，選擇含功率的運動模式

以 Suunto 9／Spartan 為例，在設定 → 連線 → 配對感測器選 Foot Pod。移動腳，等配對完成；在已配對裝置的 Foot Pod 設定關閉自動校正。到手機 Suunto App 選手錶 → 自訂運動模式，建立含「功率」欄位的跑步畫面並同步。用該模式起跑，確認功率隨腳步更新。

Race、Vertical 等系列可依錶上可用的感測器或 SuuntoPlus 選項設定。Ambit 3 若要功率須以 Power POD 配對，Ambit 3 Run 不支援 Stryd 功率。Suunto 各型號差異 · 原廠分機型設定

Polar｜在 Polar Flow 加入功率欄位

以 Pacer Pro、Vantage 為例，手錶選設定 → 一般設定 → 配對與同步 → 配對感測器，把跑鞋移近手錶確認配對。Duo 只選一個 Stryd5 或 StrydX。到 Polar Flow 編輯「跑步」運動內容，在 Training Views 加入功率，儲存並同步。

手錶選同一運動內容，等步頻感測器圖示常亮，小跑時切到功率欄。若 Polar Flow 活動已進入 Stryd，可於 Stryd 裝置頁離線同步補進階指標。原廠 Polar 設定

Amazfit Balance 2｜在運動配件新增 Stryd

以 Zepp 更新手錶後，在錶上「設定」→ Workout Accessory 選自己的 Stryd5 或 StrydX。進入跑步模式 → Settings → More → Data Page，加入 Stryd Power；試跑時確認瓦數有變化。要讓跑後活動進入 Stryd，在 Stryd App 設定 → Connected Accounts 連接 Zepp。原廠 Balance 2 步驟

Wahoo ELEMNT RIVAL｜儲存 Foot Pod 並加入功率

在手錶設定 → Sensors → Pair New，移動腳，選 Footpod 並儲存。用 ELEMNT 手機 App 開啟 Workout Profiles → Running → Workout Pages，在常用頁加入功率。手錶選 Running，移動時確認瓦數更新。若要自動送到 Stryd，在 Stryd App 的 Connected Accounts 連接 Wahoo。原廠 RIVAL 步驟

沒有相容跑錶｜用手機記錄

將手機帶在身上，在 Stryd App 查看感測器已連線，進入行事曆 →「＋」→ Start Run，選戶外或室內再開始記錄。移動時應出現瓦數；跑完停止、儲存，回到行事曆開啟這筆活動。手機首跑圖解

使用 RQ 跑力｜檢查這筆跑步有沒有瓦數
  1. 先連接紀錄來源。Garmin 或 COROS 用戶可在 RQ App「更多」→「連接裝置」選對應品牌，以平常記錄活動的帳號授權。Apple Watch 用戶先確認該筆活動已寫入 iPhone「健康」，再於 RQ 的「連接裝置」→「健康」授權，從紀錄列表上傳。
  2. 儲存短跑，再檢查同一筆活動。先確認 Garmin Connect、COROS 或 Stryd 有本次瓦數，再到 RQ 行事曆開啟相同日期與起跑時間的跑步，查看是否有功率數值或曲線。若只有時間、距離，先保留原始紀錄；該路徑的功率傳送仍待確認。
  3. 使用其他錶款或缺欄位。有原始 FIT 檔時可用 RQ 網站的「上傳紀錄」手動匯入。若活動在 Stryd PowerCenter，於電腦開啟行事曆，選該次活動並下載 FIT。另經 Strava 轉傳可能減少資料；同一筆跑步以單一來源為主，若已匯入但缺欄位，先向客服確認，避免重複上傳。
